# AI 分层记忆提取与人工介入

状态：作者已于2026-10-01回复“采用”，书面规格已批准；不代表已实现。

## 目标与现有边界

作者提供完整设定、大纲、阶段规划，由 AI 生成可编辑的分层记忆候选；作者不必逐段手工编写，但正式启用仍需确认。保留表单和高级 JSON 人工入口。复用 StoryMemoryService 的来源校验、版本卡与 ScopedContextService 的按剧情点检索，不改写正文、不自动批准、不自动恢复写作。

现状：来源引用包含项目、版本、字段、哈希与字符范围；卡不可原地修改；当前页面仅支持人工整理。模型统一使用 ModelRequest/ModelProvider，配置通过已有模型档案与密钥库读取。当前旧空卡保留，不修改其历史。

## 方案选择

采用串行分块提取、持久化进度和人工合并确认。全文单次提取实现简单但重现上下文/输出超限；多 Agent 并发提取速度可能更快但增加限流和合并复杂度，本次不采用。提取与写作共享现有项目调用互斥检查，不能声称覆盖其他设备或其他程序的同 Key 并发。

## 输入与分层

- 冻结当前已批准设定、总体大纲、阶段规划及作者选择的已批准正文变化；不读取其他项目或未批准正文。
- 原文按字段/段落拆分，超长段落再按字符范围拆分；原文与偏移不丢失。
- 不将 title、kind、author_locked 等结构字段要求作者逐项摘要；它们作为来源元数据保留，author_locked 对应锁定语义不能遗漏。必须有明确可测试的字段规则，不能简单跳过所有非字符串值。
- 输出复用 rule、character、fact、foreshadowing、summary，附实体、限定规划版本的剧情点、生效/结束章号、最早揭示章号、知晓范围与原文片段引用。
- 引用由模型返回本块来源 ID 与区间，服务端还原完整引用；不得信任模型提供的项目 ID、哈希或版本号。跨块/跨项目/虚构引用拒绝。
- 未能确定分类、关联、人物状态冲突的来源保留为待确认项；不把“模型提到来源”当作语义完整证明，也不自动用原文填充全局规则来凑覆盖。

## 有界调用与恢复

- 页面先选择现有模型档案，展示目标地址/模型、资料范围、块数及本地估算；提交明确确认后才发送资料。不显示密钥。
- 按作者2026-10-01修订，默认单块完整请求输入上限 64000 本地估算 tokens，输出预算 64000 tokens。有效输出取64000与模型档案/供应商最大输出能力的较小值；有效输入取64000与“上下文窗口－有效输出预算－1024安全余量”的较小值。上下文过小则继续拆分或调用前阻止，不擅自提高模型档案宣称的能力。估算不冒充供应商用量。
- 单次作者授权最多 8 次串行模型请求，最多预留 512000 输出 tokens（8×64000；页面按实际有效预算展示，并再次明确确认）；达到预算暂停，作者可明确继续下一批。这是上限，不要求生成这么多内容，提取仍须精简。每块最多 1 次尝试，无自动 retry/fallback/二次修复调用。
- 每块保存来源指纹、参数快照、状态、尝试 ID、时间、用量及安全错误分类。超时用量未知保持 None，已成功块可复用；失败/未知结果块需要人工确认才再次发送。
- 重复点击使用持久化领取/幂等保护；重启后 RUNNING 不自动重新发送，转为需人工核对。只取消未发出的块；本地取消不能保证供应商停止计费。
- 分块结果逐个保存，全部覆盖完成才形成完整候选卡；部分结果可查看，不可误标完整或自动批准。来源/基础卡发生变更时，禁止直接采用旧合并结果。

## 人工编辑、锁定与差异

- 人工表单与高级 JSON 始终可用；编辑保存新版本，不覆盖旧卡。增加稳定条目 ID、来源（人工/AI）和作者锁定标识，兼容现有条目。
- 作者可编辑 AI 候选文本、分类、关联、范围及秘密揭示时间。模型不得解除锁定。
- AI 更新只提出增删改建议。锁定条目逐字段保持原值；新来源与锁定条目冲突时显示冲突，作者决定解锁/修订，不静默覆盖。
- 差异页按稳定 ID 对比文本、分类、引用和范围；作者确认合并后生成新草稿，再沿用现有覆盖检查与批准步骤。未确认提取结果不进入写作检索。
- 来源内容、模型/提取规则版本、相关关联元数据和基础卡锁定状态构成缓存键；仅复用仍有效的成功结果。变更/删除来源和相关依赖重新校验，不承诺跨模型复用。

## 数据与页面

新增提取任务、分块及尝试记录，迁移只增加结构，旧卡和工作流不自动切换。任务记录不存密钥；失败响应沿用安全脱敏策略，不将供应商错误正文混入记忆内容。

记忆页新增“AI 整理记忆”，保留“手动整理”。任务页显示待处理/成功/失败/需确认块及预算；候选页提供差异、编辑、锁定、合并。GET 无模型调用。所有状态变更使用 CSRF、防重复提交和项目归属校验。

## 验收与部署

离线 FakeProvider 验证：中文超长来源拆分无遗漏、每次调用输入有界、串行且不超过8次、重复提交不重复调用、错误/超时不重试、来源变更阻止采用、引用伪造拒绝、锁定保持、人工编辑可用、差异确认前不影响正式卡、增量只处理失效块、旧版本兼容。

运行新增与全量 pytest，最后独立审查。开发不发送真实小说资料。真实提取由作者在页面确认执行；部署前检查无活动调用、备份数据库、迁移并重启。源码提交按明确文件清单，不混入当前大量未提交历史改动。
