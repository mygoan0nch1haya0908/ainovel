# 可视化模型接口与密钥保护规格

状态：用户已于 2026-09-23 确认书面规格。日期：2026-09-23。

## 目标与现状

作者希望通过页面填写 Base URL、API Key，手动填写模型名称或主动获取模型列表，再在小说生成时选择配置，避免密钥泄露。首版支持 OpenAI 兼容 Chat Completions JSON Object 协议；不假设所有兼容服务支持严格 JSON Schema 或相同厂商参数。

当前注册表固定 fake/ollama/openai/qwen，Qwen 使用 Chat Completions，现有 openai 适配器使用 Responses。新增通用适配器，不将两者错误混用；保留现有环境配置和旧工作流。当前三层大纲与默认 v2 的未提交修改完整保留。

## 页面与操作

- 新增“模型接口配置”：名称、远程/本机类型、Base URL、密码型 API Key 输入、模型名称、上下文和输出上限、启用状态。
- 保存、替换密钥、停用、删除需要 POST + CSRF；GET 与保存不访问服务商。验证失败不回显提交的密钥；成功后输入框为空，只显示“已配置/未配置”，不显示密钥尾部。
- “检查配置”为纯本地校验；“获取模型列表”为明确授权的网络请求；“测试连接”为独立确认的短合成请求，提示可能收费，不发送小说内容。
- 获取列表失败仍可手填模型名；列表有数量、条目长度及响应体大小上限，只显示转义后的模型标识，不显示任意服务商原始对象。
- 创建单章任务、阶段路线图及批次时可选择配置；明确显示目标主机和模型，并确认稿件将发送给该服务商。保留现有本地演示和环境 Qwen 入口。
- 本机模型允许无密钥；远程模型要求配置密钥。首版不支持任意自定义 HTTP 头、URL 中携带令牌、代理配置或上传密钥文件。

## 密钥与威胁边界

- Windows 当前用户 DPAPI 加密密钥；应用库只保存不透明凭据引用，密文保存在 D 盘独立运行目录的凭据库，不纳入源码、普通小说导出或诊断包。
- 用户主动在密码输入框输入密钥，浏览器将它一次性 POST 到本机后端，这是必要的短暂明文处理；不使用 localStorage、URL、cookie 或会话保存密钥。后端仅在加密及调用模型时短暂解密，不承诺可证明的进程内存擦除。
- 非 Windows 平台或加密失败时拒绝保存密钥，绝不回退明文或硬编码加密密钥。离线测试注入测试凭据库，另做 Windows 本机加解密测试。
- 密钥、Authorization、原始 SDK 异常及错误响应体不写入应用日志、审计、快照、工件或用户错误页。错误只使用固定分类与安全计数；请求验证异常也不得包含秘密字段。
- 配置名称、模型名等非秘密文本也禁止直接等于所提交密钥；URL 不允许 userinfo、query、fragment，避免常见误填泄露。无法防止作者主动把秘密填入小说或任意普通文本，应在页面提醒。
- 网络发送密钥给用户选择的目标服务是正常认证，不是“密钥从不离开电脑”。恶意服务商、同一 Windows 用户下的恶意进程、管理员及被攻陷的浏览器不在可完全防御范围；加密不能代替设备安全。
- 本地站点继续仅监听 loopback，不作为公网多用户服务；配置页 no-store、无第三方脚本/遥测、不加载服务商返回的 HTML。

## 出站地址与请求保护

- 远程配置只允许 HTTPS，TLS 验证不可关闭。拒绝私网、loopback、链路本地、保留、多播及云元数据地址，覆盖 IPv4/IPv6、混合 DNS 答复及规范化绕过。
- 本机配置需要显式选择，只允许 loopback；不将“一般内网”当作本机授权。HTTP 仅限此模式。远程密钥不可自动沿用到本机或另一个主机。
- 保存时做语法验证；网络操作前解析并验证全部目标地址。连接必须绑定已验证目的地址，同时保留正确 Host/SNI/TLS 主机验证，避免检查后重新解析导致 DNS 重绑定；若当前传输层无法满足则阻断，不以仅解析一次冒充完整防护。
- 禁用环境代理、跨目标重定向和隐式 SDK 重试。模型列表、连接测试与生成统一使用安全传输路径，有连接/读超时、响应大小和总调用上限。
- Base URL 是用户授权的认证目标；页面明确展示规范化主机。更改地址生成新版本，必须重新输入密钥或明确确认复用到新目标，默认不复制密钥。

## 配置版本与工作流

- 配置元数据版本化：端点、协议、模型及能力上限不可原地改变已经绑定的任务。新任务固定具体配置版本，快照只保存版本引用和安全元数据，不含明文或密文凭据。
- 凭据替换产生新的凭据版本；旧任务不静默切换模型、端点或密钥。旧版本允许停用/撤销，已撤销任务明确暂停，不能回退环境默认模型。
- 删除为撤销与秘密销毁：保留被历史任务引用的非秘密元数据，删除对应凭据；旧任务再次运行时提示配置不可用。删除前提示受影响任务。删除不保证清除用户此前制作的备份。
- 阶段生成、单章流程、诊断和错误路径都使用同一版本解析规则；配置操作与正在执行的请求存在并发时，已经发出的请求不可撤回，界面明确说明。
- 自定义 Token 上限受系统预算封顶；不通过模型列表推测能力，不绕过章长、修补次数、阶段进度或作者批准关卡。兼容接口仍须通过本地结构校验。

## 验收与实施边界

1. 离线模拟完整页面增删改、手填/列举模型、选配置启动任务；全部修改有 CSRF，GET/保存零网络请求。
2. 使用醒目的伪密钥，断言响应、日志、审计、SQL 数据库、提示词及导出不包含它；错误、超时、恶意响应和验证失败路径同样覆盖。
3. DPAPI 密文不包含伪密钥，当前用户可解密，异常路径安全失败；不对跨账号可移植作承诺。
4. 模拟 DNS 重绑定、重定向、内网和 IPv6 绕过、环境代理、超大模型列表；被拒绝时不发送认证信息。
5. 配置修改/删除/停用不改变旧任务绑定；新增迁移兼容已有库，并保留既有 Qwen、v1/v2、三层大纲测试。
6. 默认测试完全离线；真实获取列表或连接测试必须由作者在页面主动操作，不自动测试真实密钥。

实施前需书面规格确认，随后制定可审查实施计划。实际测试库升级前备份；仅空闲时重启服务；不自动推送、合并或调用模型。
