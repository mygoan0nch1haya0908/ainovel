# 章节安排：作者反馈修订

在最新待确认安排或当前采用的安排中展开“提出修改意见”，填写意见并确认保存。

1. 保存只建立待生成的新版本，不调用模型；原版、当前采用版本和正文保持不变。
2. 新版本显示本次意见及模型目标。点击“按意见生成修订版”才调用模型，原有发送确认、用量与尝试上限继续有效。
3. 返回完整新安排后，展示相对修改前版本的差异（不是相对空白或无关的批准版）。没有变化会明确提示。
4. 作者确认后才采用新安排；差异和历史版本仍可查看。若未满意，可继续提出意见。

修改意见、来源版本 ID 和来源安排内容放入已有不可变 input_snapshot 的 revision 字段，不需要数据库迁移。请求只携带一份来源安排和本次意见，不递归累积历史反馈。已确认正文节点由当前批准版的前 confirmed_chapters 个节点约束，批准时再次逐字段校验，不允许覆盖。

存在活动写作或待审批正文时暂不开放修订；过期来源、跨阶段来源、重复提交旧页面和无效输入均拒绝。保存继承来源的模型配置版本与预算，不能借此静默更换服务商。API 密钥不会加入意见快照。

对于超出模型上下文的新意见，原有输入预算检查会停止调用；不会裁剪作者意见。AI 是否完整落实意见仍需作者核对，系统不声称自动保证语义一致。
